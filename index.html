Radiografía: Chrome DevTools

Chrome DevTools es el conjunto de herramientas de desarrollo integrado en Google Chrome. Permite inspeccionar y depurar HTML, CSS y JavaScript, analizar el rendimiento de la red y medir la accesibilidad o el rendimiento de una página desde el propio navegador.

Información ampliada

Se abre con F12 o con Ctrl + Mayús + I (en macOS, Cmd + Opción + I).

Sus paneles principales son: Elements (DOM y CSS), Console (mensajes y ejecución de JS), Sources (depuración paso a paso), Network (peticiones HTTP) y Performance (análisis de rendimiento).
